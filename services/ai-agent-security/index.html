04 / FAQ

Before we begin.

Do we need to share our model weights or proprietary methodology?

No by default. Most assessments begin with architecture, test access and agreed behavior. Additional source or configuration access is defined during scoping only when required.

Is this only prompt-injection testing?

No. Prompt injection is one mechanism. We test the boundaries between model outputs, tools, authorization, memory, data sources and infrastructure.

Will testing disrupt production?

We agree on test environments, rate limits, sensitive assets and stop conditions before testing. High-impact validation is performed only within explicitly authorized constraints.

What happens after a finding is confirmed?

We provide reproduction details, supporting evidence, realistic impact, fix guidance and a discussion with the responsible engineering team.
